1. VISÃO GERAL DO PROJETO
O GeoMTR é um protótipo de sistema web desenvolvido para fins acadêmicos,
proposto para apoiar a organização fictícia GeoMTR Gestão Mineral na gestão
administrativa e no acompanhamento técnico-operacional de setores, operações,
empresas associadas e relatórios técnicos.

Nota de escopo: Os dados apresentados no protótipo (setores, operações,
usuários, empresas, indicadores e mapa esquemático) são exclusivamente
fictícios e demonstrativos, não substituindo laudos técnicos, licenciamentos
ambientais ou registros oficiais junto aos órgãos competentes.

3. COMO EXECUTAR O PROTÓTIPO WEB (FRONTEND)
--------------------------------------------------------------------------------
1. Acesse a pasta do site (Site.....Prot/).
2. Abra o arquivo "index.html" diretamente em qualquer navegador moderno
   (Chrome, Edge, Firefox) ou utilize uma extensão como o Live Server (VS Code).
3. Na tela de login demonstrativo, selecione o perfil desejado para navegar
   entre a Visão Operacional (Funcionário/Geólogo) e a Visão Administrativa.

Estado atual da persistência:
- Os dados iniciais são carregados a partir de "js/dados.js".
- Novos relatórios cadastrados são salvos localmente no navegador via
  "localStorage".
- Cadastros e edições em setores, operações e funcionários operam em
  memória durante a sessão demonstrativa.

--------------------------------------------------------------------------------
4. COMO EXECUTAR OS SCRIPTS DO BANCO DE DADOS (MYSQL 8.0+)
--------------------------------------------------------------------------------
O banco relacional foi modelado de forma independente e pode ser executado em
qualquer instância MySQL 8.0 ou superior (via MySQL Workbench ou terminal),
respeitando a seguinte ordem de execução:

  1º) Arquivos DB/01_BANCO_BASE.sql
  2º) Arquivos DB/MIGRACAO_SETORES.sql
  3º) Arquivos DB/SEED_DEMO.sql

Observação: Na versão atual do protótipo, o arquivo "backend/server.js"
contém a configuração inicial de conexão com o MySQL e uma rota de teste,
estando a integração completa via API REST planejada para a próxima etapa.
